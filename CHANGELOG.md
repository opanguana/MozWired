# Changelog

All notable changes to this project are documented here. The project follows
[Semantic Versioning](https://semver.org/) and uses Conventional Commits.

## [Unreleased]

### Added

- Baseline development, testing, formatting, and recovery documentation.
- Reference storefront with campaign masthead, service categories, and responsive card collections.
- Independently configurable primary and secondary storefront actions.
- Responsive global navigation and accessible mobile menu.
- Automated formatting, linting, testing, and production-build checks in GitHub Actions.

### Changed

- Updated Next.js within the existing major version to address published security advisories.
- Replaced the client-only root shell with a semantic server layout and metadata.

### Removed

- Unused runtime dependencies for animation, typography, and the legacy shadcn CLI.
